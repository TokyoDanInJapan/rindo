# Contributing

Thanks for your interest. Rindo is a personal project, but issues and pull
requests are welcome.

- **License**: the code is under the
  [PolyForm Noncommercial License 1.0.0](LICENSE). By submitting a pull
  request you agree that your contribution is provided under the same
  license, with the repository owner as licensor.
- **Data**: don't add bundled datasets without stating their source and
  license terms in the README's "Data terms" section. The upstream services
  (JMA, JARTIC, MLIT) have their own terms - notably JARTIC limits its data
  to private use.
- **Before opening a PR**: `flutter analyze` and `flutter test` should both
  pass; CI runs them on every PR.

For bugs, an issue with the closure/radar area affected (rough lat/lon) and
a screenshot goes a long way.
